## Highlights

- **Ask follow-up PR questions and review with a lens.** Investigations use a
  pinned, isolated WSL Git worktree so answers can refer to the actual code.
  Lens findings stay private until you select and confirm which comments to
  post to Azure DevOps; partial or uncertain posting is reported explicitly.
- **Keep control of Copilot Fix.** Output delivery and exact-run Stop remain
  responsive when a log follower stalls. Read older output without being
  pulled back to the bottom, resume following when ready, and retry a failed
  log read without starting another Fix.
- **Keep your settings edits.** Failed saves and unrelated responses preserve
  unsaved drafts. Settings contains keyboard focus and restores it when closed.
  Additional Fix instructions append guidance without replacing Custom Ask.
- **Read and navigate PRs more easily.** Expanded details have clearer layout,
  keyboard-accessible expansion and identity cues in narrow windows. Completed
  history is read-only, with retained run output still available.
- **Updated bundled Copilot SDK.** The release includes SDK 1.0.34.

## Privacy and validation boundaries

Investigations and Explain send selected PR/source context to Copilot. WSL Fix
is optional, runs with broad permissions and is not a sandbox. Azure Speech
processes narration in Azure and may incur charges. Viewing PRs does not require
WSL, Copilot or Speech.

Release checks cover offline native/frontend regressions and installation on a
disposable Windows runner, including synthetic PoP pages. They do not establish
live private-tenant sign-in, ADO/model compatibility, or a human listening
judgment of generated videos. Full tenant PoP sign-in validation remains
outstanding in [#15](https://github.com/alanmeadows/adoprview/issues/15).

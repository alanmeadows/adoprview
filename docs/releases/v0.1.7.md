## Highlights

- **Choose where Fix runs.** Windows is the default; WSL is an explicit opt-in.
  Configure the selected backend's repository checkout path, and choose an
  installed distro for WSL. Switching keeps inactive settings and never changes
  an existing run's backend. There is no silent fallback or automatic replay
  after interruption.
- **Windows Fix launches through a per-user broker.** An on-demand Task
  Scheduler task launches the pinned supervisor outside the dashboard's host
  job, addressing Windows launch error 5. It uses your current interactive login
  at least privilege, without a password, elevation or automatic restart.
  Exact-run Stop, retained work and reconnect across dashboard upgrades remain
  available; policy or uncertain-dispatch failures report a blocker.
- **Read Explain without streaming interruptions.** A waiting indicator and
  Cancel stay available while the explanation runs. Completed Markdown appears
  when ready, preserving selection and reading position across rerenders.
  Failed or cancelled drafts stay hidden with an explicit status and Retry.
  Fix live logs are unchanged.
- **Optional diagrams clarify explanations.** Small evidence-grounded Mermaid
  flowcharts and sequence diagrams render locally in completed explanations and
  attached-context previews. No diagram is needed for ordinary prose. Invalid
  or unsafe diagrams show an explicit error and escaped source while keeping
  the explanation readable.
- **Better evidence for PoP sign-in problems.** Correlated pane and host-window
  lifecycle diagnostics help trace navigation, website-close and browser-process
  failures without logging URLs, page contents, cookies or PR identity. Native
  regression coverage now checks a synthetic redirect, callback and return.

## Upgrading and setup

Installed v0.1.4 through v0.1.6 copies can check for this release in Settings.
Portable copies use the release-page download; v0.1.3 and earlier need a manual
upgrade. Windows Fix requires permitted current-user Task Scheduler registration
and an interactive login, plus the configured Windows Git checkout and compatible
full Copilot CLI. WSL Fix requires an explicit distro and its checkout mapping.
Questions and focused reviews remain native Windows, independent of Fix.

## Privacy and validation boundaries

Selected PR/source context is sent to Copilot. Fix has broad permissions and is
not a sandbox. Scheduler launch does not promise survival across logout or
Windows shutdown.

Offline and disposable native/browser checks cover launch ownership, reconnect,
completed explanations, safe diagram rendering and synthetic PoP return behavior.
Agents did not verify production authenticated Fix, a real WSL Fix run, or final
successful real-tenant PoP sign-in acceptance. Diagnostic and synthetic coverage
is not proof that every live sign-in problem is resolved. Disposable Windows CI
covers packaging and installer paths; installers remain unsigned.
